# Outsite inventory reconciliation - 28 October 2026

Source files supplied by the owner: OUTSITE DOOH 2026.pdf and Available ( OCT 2026).pdf.

- Added 16 missing listings: eight digital sites and eight static/package offers.
- Corrected coordinates for 16 existing records using supplier inventory map embeds. Existing non-map billboard fields were preserved, apart from the separately authorized H-14050 supplier correction and H-14156 static specification correction.

- No existing static records were removed. H-14156 was protected as a static Mosheer listing. At the owner's explicit follow-up request its legacy digital classification was corrected to Billboard / Uni-pole using static reference U05: 24 x 8 metres, two faces, one unit and EGP 500,000 monthly customer price. Code, slug and correct original photo bytes were retained; English/Arabic names, description and ALT were corrected. Its secondary image was an exact duplicate of Dahshour screen H-14216; the owner explicitly authorized removing only that incorrect image.
- Per the subsequent explicit instruction, H-14050 retained its code, slug and non-supplier fields, received the two new B01 photographs with the Horizon frame, and moved from supplier 48 to Outsite OOH (277). Its old photograph is backed up privately.
- Existing prices were preserved. New prices are customer selling prices, as confirmed by the owner.
- Galleria digital-only D04 and combined static/digital C07 are separate offers at the owner's explicit request.
- Pixel dimensions are labelled as pixels in descriptions and never stored as physical metres. Missing static illumination specifications remain unspecified.
- Only new photographs and the authorized H-14050 replacement were retouched and framed at 640 x 380. Other correctly framed retained photographs keep their original image bytes. Two broken references (H-14155 and H-14309) were repaired using the identical framed original files; no photograph was re-edited.
- New mega-post sequence H-14514 uses an approximate roadside package pin near the supplier's adjacent Hilton Pyramids Golf map; individual posts have not been surveyed.
- Full before-state and original image files remain in private server backups, outside Git.
